# ptusa Lua debugger client

Windows-клиент для Lua-отладчика `ptusa_main`. Приложение подключается к
сервису 2 на TCP-порту 10000, автоматически создаёт серверную сессию и
поддерживает её периодическими запросами.

Возможности:

- список Lua-выражений и отображение их последних значений;
- графики числовых и логических выражений в реальном времени;
- интервал опроса от 100 до 9000 мс;
- долгосрочная клиентская история: 5000 точек на выражение по умолчанию,
  лимит настраивается в окне программы;
- разовое вычисление Lua-выражения;
- сохранение и загрузка адреса, интервала, лимита, выражений и полученной истории.

Сервер по-прежнему хранит только короткий кеш последних 128 изменений. Клиент
объединяет ответы сервера без повторов и независимо хранит выбранный объём
истории для долгосрочного отображения.

## Запуск из исходников

```powershell
uv sync --group dev
uv run ptusa-lua-debugger
```

## Проверка

```powershell
uv run pytest
```

## Сборка Windows EXE

```powershell
.\build.ps1
```

Результат: `dist\PtusaLuaDebugger.exe`.

Для создания установщика установите Inno Setup 6, добавьте `ISCC.exe` в
`PATH` и выполните:

```powershell
.\build.ps1 -Installer
```

Результат: `installer\PtusaLuaDebuggerSetup.exe`.
