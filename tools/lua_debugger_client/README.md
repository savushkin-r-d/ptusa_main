# ptusa Lua debugger client

Windows-клиент для Lua-отладчика `ptusa_main`. Приложение подключается к
сервису 2 на TCP-порту 10000, автоматически создаёт серверную сессию и
поддерживает её периодическими запросами. Интерфейс использует тёмную тему
`qt-material`.

Возможности:

- несколько независимых вкладок для одновременной отладки разных
  контроллеров;
- дерево Lua-выражений: текущее значение и состояние в основной строке,
  предыдущее значение и статистика при раскрытии;
- настройки каждой линии в раскрытой строке: имя в легенде, цвет, сдвиг по Y
  и точки изменений; сдвиг применяется только на графике;
- тип графика для каждого выражения: ступени по переднему краю (значение
  удерживается после точки), по заднему краю (до точки), по середине интервала,
  линия или только точки; выбор применяется сразу и сохраняется в сессии;
- индивидуальный флаг «История»: графики и долговременное накопление только для
  выбранных выражений;
- единая событийная таблица истории с пустыми ячейками для неизменившихся
  выражений и экспортом в Excel;
- графики числовых и логических выражений по времени контроллера;
- вычисляемые счётчики серий импульсов: задаются имя, Lua-выражение
  считаемого датчика и его целевое значение, выражение ведомого датчика
  и его целевое значение. Первый импульс ведомого датчика фиксирует число
  импульсов считаемого датчика и начинает новый подсчёт. Результат доступен
  в дереве, истории, Excel и на графике;
- интервал опроса от 100 до 9000 мс;
- долгосрочная клиентская история: 5000 точек на выражение по умолчанию,
  лимит настраивается в окне программы;
- настраиваемое окно графика в секундах и автопрокрутка последних N секунд;
- накопительные Min, Max, среднее и медиана для каждого выражения
  за всё время наблюдения;
- разовое вычисление Lua-выражения;
- отдельная вкладка сообщений с системными логами, ошибками `error_manager`
  и событиями `set_err_msg` для каждой активной сессии;
- сохранение и загрузка адреса, интервала, лимита, окна отображения, выражений,
  флагов истории, настроек линий, счётчиков и полученной истории.

Счётчик добавляется кнопкой «Счётчик импульсов…». Значения вводятся как JSON:
`1`, `true`, `false` или строка в кавычках. Подсчёт начинается с первого
известного состояния сигналов после добавления; уже прошедшие импульсы не
восстанавливаются. Исходные выражения добавляются в опрос автоматически.
График удерживает результат последней завершённой серии; одинаковые итоги
(`10, 10, 10`) сохраняются отдельными точками истории. До первого результата
показывается ожидание. Остальные импульсы ведомого датчика не создают нули.
Для двух датчиков создайте два счётчика, поменяв считаемый и ведомый датчики
местами. Значения задаются без визуального сдвига по Y. Порога сброса нет:
серия из 11 импульсов сохраняется как 11.

Сервер хранит короткий кеш последних 64 изменений каждого выражения и последних 64
сообщений. Клиент объединяет ответы сервера без повторов и независимо хранит
выбранный объём истории для долгосрочного отображения.

Клиент получает величины и сообщения одним запросом `POLL` (команда 9),
который требует обновлённого контроллера. Сервер и отладчики обслуживаются
в чередующихся циклах PAC. Неполный TCP-пакет ожидает следующего цикла.

Новая вкладка создаётся кнопкой `+` или `Ctrl+T`. Каждая вкладка хранит
собственное подключение, список выражений, статистику и историю.
`Сессия → Открыть` (`Ctrl+O`) загружает сохранённую сессию в новую
вкладку; `Ctrl+S` сохраняет текущую, а `Ctrl+W` её закрывает.

## Запуск из исходников

```powershell
uv sync --group dev
uv run ptusa-lua-debugger
```

## Проверка

```powershell
uv run pytest
```

## Сборка Windows EXE

```powershell
.\build.ps1
```

Результат: `dist\PtusaLuaDebugger.exe`.

Для создания установщика установите Inno Setup 6, добавьте `ISCC.exe` в
`PATH` и выполните:

```powershell
.\build.ps1 -Installer
```

Результат: `installer\PtusaLuaDebuggerSetup.exe`.
